# Ayde & Octavio — Premium Floral Assets

Assets PNG transparentes generados para elevar visualmente la invitación.

## Archivos

- `floral-corner-top-right.png` — arreglo floral grande para hero/portada o esquina superior derecha.
- `floral-corner-bottom-left.png` — arreglo floral grande para esquina inferior izquierda o cierre de secciones.
- `floral-side-right.png` — arreglo vertical delgado para laterales, timeline o secciones largas.
- `floral-frame-gold.png` — marco floral/dorado para portada, padres, confirmación o lluvia de sobres.
- `floral-divider.png` — divisor horizontal para encabezados y transiciones entre secciones.

## Uso recomendado

Colocar la carpeta en el proyecto y reutilizar los assets como decoración. Para elementos puramente visuales usar `pointer-events: none`, `user-select: none` y `aria-hidden="true"`.

Mantenerlos responsivos con `object-fit: contain` y evitar que cubran texto, botones, fotos o controles interactivos.

Paleta objetivo: azul cielo/polvo, marfil, verde eucalipto y champagne/dorado.

No es necesario utilizar todos los assets simultáneamente; priorizar una composición limpia y premium.
