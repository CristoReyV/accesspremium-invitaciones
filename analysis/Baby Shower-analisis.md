### 6. Oportunidades para AccessPremium

1. **Par niño/niña en el mismo template:** BS-02 y BS-07 demuestran que un mismo formato de carnet funciona perfectamente con solo cambiar la paleta. AccessPremium puede ofrecer *"Escoge el color de tu bebé"* como variante dentro de una misma plantilla.

2. **Feature de subir fotos al evento:** BS-05 y BS-06 tienen un botón "Subir foto" para que los invitados compartan momentos del baby shower. Esto es un diferenciador de producto muy valioso que no todos los competidores ofrecen.

3. **Mesa de regalos con link a Amazon / Mercado Libre:** BS-06 integra Amazon directamente. AccessPremium puede ofrecer esto como campo personalizable.

4. **Reveal de género como extensión de Baby Shower:** El mismo diseño Safari puede adaptarse para una invitación de Revelación de Género cambiando elementos clave.

5. **Oferta de par completo:** Ofrecer portada + invitación como paquete siempre, dado que la portada/cover funciona como hook visual. La página única (BS-07) debería tener su propia portada.

6. **Géneros neutros como primera opción:** BS-01 y BS-04 funcionan sin revelar el género. El mercado premium prefiere no anticipar el género antes del evento. AccessPremium puede hacer de esto un diferenciador.

---

### 7. Recomendaciones para Mantener Variedad sin Perder Calidad

- **Máximo 2 invitaciones por paleta cromática** para evitar catálogo visualmente monótono.
- **Equilibrar géneros:** Para cada diseño "rosa niña" debe existir un equivalente "azul niño" o un diseño neutro.
- **Mantener diversidad de animales/personajes:** No saturar con animales de safari; alternar con osos, jirafas, personajes de licencia y elementos abstractos (nubes, arcoíris).
- **Variar la estructura:** Alternar entre: portada + invitación scroll / página única larga / formato carnet.
