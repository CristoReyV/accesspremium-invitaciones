## Asset policy

- Use `public/assets/templates/[categoria]/[slug]/` when concrete reusable image assets are copied into the app.
- Do not copy full static HTML.
- Do not copy extracted scripts.
- Prefer CSS keyframes and React state for motion.
- If the external `replicas` vault becomes available, re-audit it for individual PNG/SVG/font files before copying assets.
